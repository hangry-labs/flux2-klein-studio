The browser interface, project READMEs, Docker Hub product pages and introductory
guides support these six languages. The introductions explain the main workflows
and link to the technical guides below, which are maintained in English. Model
prompts, fixed adapter triggers and API identifiers are independent of UI language.

- [Browser Studio](studio.md): Generate, Refine, Gallery, System and file storage.
- [HTTP and MCP](agent-api.md): named sizes, adapters, queueing, authentication and examples.
- [Adapter guide](lora.md): generation styles, Green Fill, Red Zoom and qualification.
- [Model capabilities](model-capabilities.md): implemented features and limits.
- [Benchmarks](benchmarks.md): memory, speed and fixed-seed methodology.
- [Validation](validation.md): tested workflows, hardware and repeatability scope.
- [Container releases](RELEASING.md): standard/tiny images and publication.
- [Localization](localization.md): catalogs, language routes and translation checks.
